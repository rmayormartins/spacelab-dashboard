NOTES: como funciona, limites e licenças

Fluxo. Catálogo e transmissores vêm de db.satnogs.org/api. As observações vêm de network.satnogs.org/api/observations e cada item de demoddata é um arquivo binário com um quadro. A telemetria do DB (/api/telemetry/) exige token pessoal.

Se o navegador bloquear (CORS). Os LEDs no topo mostram o que passou. A rota garantida é o coletor em GitHub Actions deste repositório, que grava data/<norad>.json e o painel lê como arquivo local.

Motor SpaceLab. Procura a sync word 5D E6 2A 7E, lê a size tag do NGHam, remove o embaralhamento CCSDS, corrige erros com Reed-Solomon e confere o CRC-16. Os campos seguem os arquivos do spacelab-decoder (GPLv3, SpaceLab/UFSC). Os campos do GOLDS-UFSC devem ser conferidos com o primeiro quadro real.

Motor oficial. Baixa o pacote satnogs-decoders (AGPLv3, Libre Space Foundation) do PyPI e roda no navegador com Pyodide. No modo automático só é aplicado o decoder cadastrado no SatNOGS DB para o satélite. O botão "forçar decodificação" testa todos e, se nenhum cadastrado servir, aplica o melhor como PALPITE: os campos têm nomes de outro satélite e precisam ser conferidos.

Dados. SatNOGS, CC BY-SA. Valores decodificados por força bruta são hipóteses até baterem com a documentação do satélite.
